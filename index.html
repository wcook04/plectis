  1. Erdős #1041Counterexample

    A degree-seven counterexample to the formal #1041 statement

    A monic degree-seven polynomial f has seven distinct zeros in the open unit disc, yet every path in |f| < 1 joining two of them has an image of one-dimensional Hausdorff measure at least 2.

    Proof idea. ani’s polynomial creates a narrow bottleneck. Every connecting path must pass through it, giving the lower length bound.

    Boundary. This refutes the Formal Conjectures statement. Correspondence with Erdős’s 1958 wording has not received independent human review.

    Lean proofComparator checkPaper §2

  2. Erdős #257Irrationality theorem

    Irrational on every support of finite prime-weighted mass

    Let A be an infinite set of positive integers and P a finite nonempty set of primes. Let h(a) be the largest divisor of a using primes in P. If ∑a∈A h(a)/(a(2h(a)−1)) is finite, then ∑a∈A 1/(ba−1) is irrational for every integer b ≥ 2.

    Proof idea. Divisibility clears a finite prefix. Weighted averaging makes a positive remaining displacement smaller than any rational denominator permits.

    Boundary. The weighted-summability hypothesis is essential to this theorem. Irrationality for arbitrary infinite supports at base two remains open.

    Lean proofComparator checkPaper §2

  3. Erdős #243Irrationality theorem

    A cubic perturbation of squaring forces irrationality

    For every strictly increasing sequence of positive integers with an2/an+1 = 1 + 3/n + o(n−3), the reciprocal sum ∑ 1/an is irrational.

    Proof idea. A rational sum would force an eventual cubic integer-tail polynomial. Coprimality, a square relation in its cubic field, and reduction modulo seven contradict it.

    Boundary. The little-o precision is part of the hypothesis. This does not settle other integer rates or the unrestricted question.

    Lean proofComparator checkPaper §3

  4. Erdős #1049Irrationality theorem

    Irrational Lambert values across a region of rational bases

    Let F(t) = ∑n≥1 1/(tn−1). For coprime integers a > b ≥ 1, F(a/b) is irrational whenever b200 < a81. This includes every positive integer power of 31/4; the paper proves a slightly larger region.

    Proof idea. Zudilin’s 2004 hypergeometric forms are homogenised at rational bases; common polynomial factors cancel before exact denominator and decay estimates are compared.

    Boundary. The criterion excludes 3/2. The universal rational-base question remains open.

    Lean proofComparator checkPaper, Theorem 4.1

  5. Erdős #249Exact classification

    Exactly which bounded totient observables have rational sums

    Write φ for Euler’s totient. For k ≥ 1 and f: ℤ/2kℤ → ℚ, ∑n≥1 f(φ(n) mod 2k)/2n is rational exactly when f is constant on the even residue classes. If that constant is c, the value is 3f(1)/4 + c/4. Also, ∑ (φ(n) mod m)/2n is irrational for every m ≥ 3.

    Proof idea. Congruence constructions isolate a nonzero totient residue between long zero blocks. Bounded tails then conflict with rationality’s fixed denominator.

    Boundary. This classifies bounded residue observables. Irrationality of the series with unreduced totients remains open.

    Lean proofComparator checkPaper §4

  6. Erdős #1041Geometric theorem

    Every monic trinomial admits short radial connections

    Let 1 ≤ m < n and f(z) = zn + azm + b have every zero in the open unit disc. For each zero ζ, the entire segment [0, ζ] lies in |f| < 1. Any two distinct zeros therefore connect through 0 by a path of length below 2.

    Proof idea. The root equation eliminates the middle monomial. Along the segment, only b and −ζn remain, with nonnegative weights and moduli below one.

    Boundary. The theorem controls segments ending at zeros. A sextic with one additional term shows that the prescribed radial segments can fail.

    Lean proofComparator checkPaper §3

  7. Erdős #251Limitation of a proof method

    Sparse congruence-preserving corrections fill an interval

    Let an be nonnegative integers with A = ∑n≥0 an/2n+1 finite, and let f(n) → ∞. Corrections 0 ≤ en ≤ f(n) eventually, supported on one set of upper Banach density zero, make ∑n≥0 (an+en)/2n+1 fill a nondegenerate interval above A. For every fixed modulus, en and its cumulative sums eventually vanish modulo it.

    Proof idea. Spaced blocks encode arbitrary target digits; factorial divisibility preserves all fixed congruences while block spacing makes the support sparse.

    Boundary. Applied to prime gaps this produces comparison sequences, not primes. Irrationality of the actual prime-value dyadic series remains open.

    Lean proofComparator checkPaper, Proposition 1.1

  8. Erdős #243Rigidity theorem

    A one-sided 1/n bound forces the Sylvester recurrence

    Let positive integers a1 < a2 < ⋯ satisfy an+1/an2 → 1 and have rational reciprocal sum. If an2/an+1−1 ≤ 1/n + K/n1+ε eventually, for some K ≥ 0 and ε > 0, then an+1 = an2−an+1 eventually.

    Proof idea. Transfer the one-sided growth bound to integer-tail increments. Stable coprimality and a Chinese-remainder first-crossing barrier force the errors to vanish.

    Boundary. Rationality and the growth bound are hypotheses. The unrestricted Sylvester-rigidity conjecture remains open.

    Lean proofComparator checkPaper, Corollary 4.10

  9. Erdős #249Structure theorem

    An exact basis for totient sections in every base

    Write φ for Euler’s totient. For integers k ≥ 2 and e ≥ 1, the sequences n ↦ φ(kjn+r), with 0 ≤ j ≤ e and 0 ≤ r < kj, span a rational vector space of dimension ke+1. A basis consists of φ(n), φ(kn), and the sections with j ≥ 1 and k ∤ r; every omitted section has an explicit scalar reduction.

    Proof idea. Totient multiplicativity gives the scalar reductions. Arithmetic separation of affine totient values proves that the retained sections are independent.

    Boundary. This is a structure theorem for sequences. Their large span does not imply irrationality of the binary totient sum.

    Lean proofComparator checkPaper §2

  10. Erdős #269Limitation of a proof method

    Three-prime LCM kernels have nonzero minors of every order

    Let p, q, r be distinct primes, H(t) the running LCM of the {p,q,r}-smooth integers up to t, and K(i,j,k)=1/H(piqjrk). For every order n, there are n distinct rows and columns whose determinant is nonzero in every layer k. Thus K has no finite rational decomposition ∑ fℓ(i)Gℓ(j,k).

    Proof idea. Rescale rows and columns to a two-valued carry matrix. Dense logarithmic fractional parts select triangular minors with determinant c(c−1)n−1, c=1/r.

    Boundary. This blocks every finite separation of that form. It does not prove irrationality of either three-prime running-LCM sum.

    Lean proofComparator checkPaper, Appendix B

  11. Erdős #68Denominator bound

    Factorial-gap common denominators grow faster than exponentially

    For LN = lcm(2!−1, 3!−1, …, N!−1), lim infN→∞ log LN/(N3/2 log N) ≥ 2√2/3. This bounds the common denominator before reducing the reciprocal partial sum.

    Proof idea. Compare a terminal block’s product with its LCM and pairwise gcds. Optimising its length near √(2N) gives the constant.

    Boundary. The theorem bounds the unreduced common denominator. Cancellation and irrationality of ∑n≥2 1/(n!−1) remain unresolved.

    Lean proofComparator checkLong paper §3

  12. Erdős #257Measure theorem

    A Mersenne subsum set has an exact measure dichotomy

    For allowed positive exponents J, let AJ = {∑n∈J εn/(2n−1): εn∈{0,1}}. If J omits exactly m exponents, its Lebesgue measure is 2−m; if J omits infinitely many, its measure is zero. Every value has a unique digit sequence, and AJ is perfect when J is infinite.

    Proof idea. Each Mersenne weight exceeds the entire remaining tail. Disjoint cylinder intervals give unique coding and measure by continuity from above.

    Boundary. Measure and unique coding do not decide which rational numbers occur, or whether every infinite subsum is irrational.

    Lean proofComparator checkPaper, Appendix C.2

  3. 28:58

    The long version

    The route it takes

    The long version runs half an hour, so what follows is the route it takes rather than every word. The one- and five-minute transcripts above carry the same argument verbatim.

    The problem. The system has outgrown what I can hold in my head or an agent can hold in context, and building got easier before understanding could catch up. So the priority became inspection: what ran, what changed, what evidence backs a claim, what's missing, and what the unknown unknowns are.

    What it is. One backend with two front ends. The visual one is for human reading and exploration; the kernel is the agents' equivalent, reached through routes and context packets. Same information, shaped for each reader.

    That it's real. Agent Trace is shown live, with real agents working concurrently, because that's harder to fake than a screenshot. Nothing on screen is hard-coded; it's derived from the backend, so the views and the source can't quietly drift apart.

    How agents navigate. Kernel routes, standards, and contracts. A standard defines what a thing has to satisfy, and the check is mechanical rather than a matter of the agent's word.

    Governance. Axioms, principles, and anti-principles sit in the repo. I can't retrain a model, so instead the environment carries the rules, and agents have refused things I asked for because the principles didn't allow them. Multi-step effects land as a transaction: a change to the world only counts once it really landed.

    How it got built. Months of thinking out loud into voice notes, mined into ideas, then grounded against the system and turned into refinements. Around thirteen thousand captures exist so that a problem noticed in one chat doesn't die there.

    Breadth. Forecasting and finance feeds fanned into a shared state, and formal mathematics with machine-checked proofs. Built solo, over roughly a year.

    The honest close. The front end I built is not to be trusted, because appearances are easy to fake. Where I could get it to run real tools, I did; where I couldn't, I say so. The evidence view is there to keep it honest by showing which routes are still incomplete. I've tried to be careful about overclaiming, because of how many repos and startups I see doing the opposite. It ends on one question: can any claim survive the path from the map to the source and the evidence?

Why I am building it

I was vibe-mathing back in early 2025, and even then I realised formal verification is necessary but not sufficient for a lay person wanting to use AI to do maths. It’s necessary because I can’t check a proof myself, so Lean is how I know a statement is actually proved. It isn’t sufficient because you can’t really replace understanding, and Lean won’t tell you whether a statement is the one you meant, whether it was worth asking, or whether anyone can follow why it’s true. A lot of mathematicians wrote about exactly this in September, De Toffoli and Duede on logical versus intelligible proof, and Henry Cohn on unexplained AI proofs as technical debt that somebody else has to pay.

Basically, the idea would be that human mathematicians provide direction. I’ve been struggling to get that, so I’ve tried to see how far you can get without any: a short paper for each problem that tries to make the argument readable, a long paper recording every route that failed, and seminar-style videos we’re trying to automate from them. It’s more of a proof of concept than me claiming I understand the mathematics deeply enough to explain it, and I’m not presupposing the videos are any good, but if an unknown person with no understanding can get even part of the way, I think that says something about what an expert could do. When one mathematician pointed out what was going wrong with how we were writing the papers, every problem paper was rewritten, and the credit ledger below lists that and every other case.

If AI is any level more intelligent than a person, I see no reason why that intelligence can’t then be applied to convert the resulting “uninterpretable” mathematics back into something that can be interpreted.

For AI readers and coding agents

JSON packets are more trusted than cloning a repo. You don’t even need an IDE or a coding app: you can simply upload one on the AI websites. It is like holding a hologram of this “universe” in your pocket, able to zoom with a queryable microscope into any part of it, and to be told what the parts even are before you look. Reading is not a verification run; a check counts as passed only when the stated command was run and its evidence shown.

Setup prompt for a coding agent

A mathematics task needs only the mathematics repository. A software task needs only the software repository. This prompt is for an assessment across both.

My task is [describe the question or change]. Use https://github.com/wcook04/plectis for software components and https://github.com/wcook04/plectis-erdos for mathematics and Lean proofs. Clone the repository my task needs from current main; use both only if the task crosses them. Preserve any existing local work. Read README.md and the compact agent entry: AGENTS.override.md where present, otherwise AGENTS.md. Record the checkout commit and local changes. For mathematics, use python3 scripts/agent_entry.py --entry with my task, and --checkout --check-upstream to compare with public main. For software, follow QUICKSTART.md and run the quickstart check or selected component example, saving output under .microcosm/. Do the task and return source paths, exact commands and outcomes, and the remaining assumptions or unresolved step. Report anything you could not run as not established, never as false. A release tag is a frozen edition, not current main.
