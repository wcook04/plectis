And so I wanted to know something quite simple. If you show the model the bugs it missed before, does it get better at catching bugs in new programs that it hasn't seen? And I'll explain the test first, then the experiment, and then what the results mean.

that has a bug in it and a bug is a mistake that gives the wrong answer for some inputs but the model can't actually see the code it only sees a description of what the code is supposed to do

so the model gets five guesses and each guess is an input and I run it through the faulty code and through a correct version and if they give different answers or the faulty one crashes then the bug is caught there's also a time limit and the correct version answers almost straight away so if the faulty one is still running after a second that counts as caught too

the faulty code is real and it was written by other AI models ChatGPT, CodeGen, and InCoder for a standard set of coding problems and it passes those problems own tests researchers behind a project called EvalPlus later found extra inputs that break it

so here's one the code should sort the numbers at every other position in a list and the description says the list can be empty the version CodeGen wrote crashes on an empty list so the only way to catch it is to think of trying an empty list first

the model practiced on 28 problems and every bug it missed went into a record the faulty code and an input that would have caught it then I gave it 58 new problems that it had never seen twice with the record added.

It's a little bit like revising for an exam. So the record is like your marked past papers, the questions you basically got wrong, with the right answer next to them.

With the past papers, the model caught more bugs. Out of the 58 new problems, it did better on 20, worse on 6, and the same on the rest. On average, it went from catching about 69% of the bugs to about 77%.

To check whether that could just be luck, I reshuffled the results many times, and the improvement held up in almost every reshuffle, so it seems to be real, although it isn't very big.

The revision tips didn't do that. None of them made a clear difference, so the model did better when it saw the actual bugs it had missed, and turning those bugs into rules didn't help.

You can see it on the empty list problem. Without the record, the model never tried an empty list, and with the record it did both times.

There's one more pattern that seems to be interesting. When the model read the rules it spent less time thinking about it before it answered and when it read the past misses it thought for longer. And when I switched its thinking off the record didn't help at all.
