Select a family, a component or a rule to light what it touches. Zoom in over the rim to read the components’ names, and drag to move round it.

How the map is drawn

Each component is a mark on the rim, in its family’s sector, and the shape of its mark says how the component is backed. A red line joins two components where the code of one runs the other, reads the results it saved or checks the files copied from it, each kind in its own texture. At the centre is the doctrine: its axioms on a ring, with the principles and failure modes tied to them. An azure line runs from a component to each rule its paper module cites.

The map of the system draws here when its script runs. The panel lists the same families as text, each a link to its page.
