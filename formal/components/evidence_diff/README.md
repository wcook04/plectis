# Evidence ID partition

`EvidenceDiff.dfy` computes a category and the final index for every normalized
ID. Its postcondition states that the four categories are exactly absent,
lab-only, oracle-only and shared, and that each present index points to the last
occurrence of that ID. Together these partition the union into extra, missed
and shared IDs. The proof applies to any finite sequences of integer ranks
within the supplied universe.

The Batch 8 tools-tail evidence exercise calls the generated kernel through
`plectis.components.evidence_diff`. The trusted Python adapter turns JSON-safe
scalar IDs into injective ranks using Python equality, chooses the original
key representatives, orders the result and projects original rows. JSON
serialization, Python's equality and sorting behavior, the adapter, runtime,
compiler and host are outside the theorem. The copied observer's prediction
comparison is a separate, unproved computation; its source snapshot is kept.

The accompanying mutant changes the shared category into the missing category;
Dafny rejects the maintained invariant. `metadata.json` records the pinned
compiler, verified build, generated file hashes and mutant result. Rebuilding
and comparing generated bytes is required before changing the source.
