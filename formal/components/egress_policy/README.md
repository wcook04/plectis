# Egress phrase matcher and policy

`EgressPolicy.dfy` specifies a literal phrase occurrence by a text position,
exact code-point equality and the gate's ASCII-alphanumeric edge rules. `Find`
scans every possible start and is proved to return true exactly when such an
occurrence exists. `PolicyExact` proves that each adjacent tripwire and
legitimizer pair produces a violation exactly when the tripwire matches and
its legitimizer does not, and that red is equivalent to at least one such
violation.

The active egress gate calls this generated matcher and decision through the
component worker. The Python adapter preserves phrase order and supplies code
points and edge flags; Python string conversion, lowercasing, `isalnum`, JSON,
the adapter, generated-code loader and execution platform remain trusted. The
proof does not establish that the phrase policy understands text or detects
all unsafe responses. Dafny, its solver and compiler remain trusted.

`negative/MissingLeftGuard.dfy` and `negative/MissingRightGuard.dfy` each remove
one executable boundary guard while retaining the specification. Both must fail
verification. `metadata.json` binds the source, the exact mutants and generated
Python hashes; the shared component checker re-verifies the proof and compares
regenerated bytes when given the pinned Dafny toolchain.
